# CyDecompilator

## Connexion

Le [guide natif](https://github.com/MrMybal/CyDecompilator/blob/main/app/Docs/CyMCPSDK.md) documente les transports et révisions. Pour la distribution Windows, utilise le Python fourni avec `app/tool.py mcp` si la configuration du paquet indique ce transport. Découvre les opérations et leurs schémas via le serveur connecté.

## Utilisation

Choisis le format d’entrée et examine le résultat de l’analyse avant de démarrer une reconstruction. Identifie la sortie, les artefacts de build et les limites constatées dans le compte rendu.
