# CyEngineHub

## Connexion

Dans Settings → AI / MCP, copie l’adresse de l’instance en cours ou utilise la CLI JSON de l’application. Vérifie le profil actif. Les opérations exposées et les autorisations de réparation sont distinctes.

## Utilisation

Résous les identifiants de projet et d’installation dans l’inventaire. Pour une conversion, lis le périmètre et la destination dans l’aperçu avant de lancer le travail demandé.
