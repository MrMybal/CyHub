# ShaderixFrame

## Connexion

Utilise `ShaderixFrameCLI.exe` pour les opérations disponibles sans interface ou la connexion loopback authentifiée pour l’éditeur ouvert. Découvre ses schémas puis identifie le projet et la timeline.

## Utilisation

Relève la piste, les ID de clips et les plages avant modification. Distingue un brouillon de clip, son application au document et la sortie d’un rendu.
