# CyInsights

## Connexion

Dans AI Inspector → Connection, copie la configuration du document. Le PID et l’identifiant de document désignent la capture cible. Commence par les capacités disponibles, les métadonnées, le budget de frame et une plage temporelle bornée.

## Utilisation

Examine les frames lentes puis les fonctions coûteuses. Charge les compteurs ou dépendances de tâches si le provider est présent. Compare les plages A et B avec la même normalisation. Identifie les mesures, déductions et hypothèses et termine les jobs une fois les rapports utiles exportés.
