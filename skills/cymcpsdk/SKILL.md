# CyMCPSDK

## Connexion

Choisis Core et MCP pour publier des opérations typées. Ajoute Http pour le transport local si nécessaire. Utilise les profils et politiques définis par l’hôte. Les modules AI et ChatUI sont optionnels pour un serveur d’outils.

## Utilisation

Décris les schémas et teste l’appel local, puis l’initialisation MCP et `tools/list` via le transport réellement livré. Vérifie les erreurs et les permissions dans le même profil de connexion.
