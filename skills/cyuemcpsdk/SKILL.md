# CyUEMCPSDK

## Connexion

Active les outils Unreal pour le fournisseur si tu utilises le chat intégré. Pour MCP, génère la configuration à partir du descripteur du PID de l’éditeur visé avec `Scripts/WriteMCPConfig.ps1`. Les profils avec jeton utilisent les paramètres de connexion de cette instance.

## Utilisation

Vérifie le projet, la carte et la sélection dans l’éditeur avant de modifier un asset. Les permissions d’édition Unreal dépendent du profil sélectionné.
