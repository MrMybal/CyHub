# CyCLAPBridge

## Connexion

Dans External assistants (MCP), démarre le serveur puis utilise Copy MCP connection. La CLI peut cibler une instance avec `--mcp-url`. Les profils avec jeton lisent `CYCLAPBRIDGE_MCP_TOKEN`.

## Utilisation

Vérifie le format, le plugin et le backend de conversion disponible. Lis les diagnostics pour distinguer une inspection, une conversion de source et un plugin testable dans l’hôte.
