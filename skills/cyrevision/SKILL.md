# CyRevision

## Connexion

Active AI Workspace dans Plugins, ouvre Code & Assets → AI Assistant → CyMCPSDK et utilise Start local MCP pour obtenir le descripteur de l’instance. La CLI couvre aussi certaines opérations hors interface.

## Utilisation

Sélectionne le dépôt et la branche avant de relever un diff, un statut ou une tâche. Les opérations attachées à l’interface reprennent les autorisations et les confirmations de l’instance.
