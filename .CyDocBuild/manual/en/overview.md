CyHub brings applications, libraries, SDKs and extensions into a searchable desktop catalog. Use the sidebar to move between project categories, updates and MCP skills.

## Start here {#start}

- [Launch CyHub and enable managed updates](doc:installation#launch).
- [Find a project and check its GitHub release](doc:catalog#search).
- [Install, update and open a managed project](doc:updates#install).
- [Connect an AI client and find a project skill](doc:mcp#connect).

## The workspace {#workspace}

The sidebar filters the catalog. The middle column lists projects with their descriptions and icons. Select a row to see versions, available actions and the project's MCP guide.
